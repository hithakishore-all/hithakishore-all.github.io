How to read these prototypes

These are my own independent prototypes and explorations, not commercial products. Every case study has a What's real panel that uses these labels, so you can tell built functionality from simulation, research and assumptions.

  • BuiltWorking code you can run: flows, guardrails, engines, tests.
  • ScriptedDeterministic stand-ins (for example, pre-written agent wording) that a live model can replace.
  • SimulatedIntegrations or systems that are mocked, such as Gong calls or a host CRM.
  • SyntheticFictional companies, people and numbers generated for the demo.
  • Public sourceFacts and market figures from cited public research.
  • AssumptionIllustrative inputs or judgments, stated as such.
  • ProposedTarget metrics for a pilot. Not results.
  • MeasuredSomething actually measured, such as automated test results.
Independent personal projects: my own ideas, prototyped and built by me. Demo data is synthetic unless a page marks a public source. Product names such as Salesforce, Snowflake, Slack, Gong and Stripe describe integrations only and imply no affiliation or endorsement. LinkedIn · GitHub
